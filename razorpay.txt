To integrate Razorpay into your project (React Native frontend + Node.js/Express backend), follow these steps:

1. Create a Razorpay Account
Sign up at https://razorpay.com/ and get your Key ID and Key Secret from the dashboard.
2. Backend: Create Razorpay Order
Install Razorpay SDK:
----
npm install razorpay
--
Sample endpoint (/api/create-razorpay-order):
----
const express = require('express');
const Razorpay = require('razorpay');
const router = express.Router();

const razorpay = new Razorpay({
  key_id: process.env.RAZORPAY_KEY_ID,
  key_secret: process.env.RAZORPAY_KEY_SECRET,
});

router.post('/create-razorpay-order', async (req, res) => {
  try {
    const { amount, currency = "INR" } = req.body;
    const options = {
      amount: amount * 100, // amount in paise
      currency,
      receipt: "order_rcptid_" + Date.now(),
    };
    const order = await razorpay.orders.create(options);
    res.json({ success: true, order });
  } catch (err) {
    res.status(500).json({ success: false, message: err.message });
  }
});

module.exports = router;
--
Don’t forget to add this route to your main Express app.

3. Frontend: Integrate Razorpay Checkout
Install Razorpay React Native SDK:
----
npm install react-native-razorpay
--
For Expo, use expo-dev-client or use Razorpay’s web checkout in a WebView.
Sample usage:
----
import RazorpayCheckout from 'react-native-razorpay';

const handlePayment = async (amount) => {
  // 1. Create order on backend
  const { data } = await axios.post('/api/create-razorpay-order', { amount });

  // 2. Open Razorpay checkout
  var options = {
    description: 'Order Payment',
    image: 'https://your-logo-url.png',
    currency: data.order.currency,
    key: 'YOUR_RAZORPAY_KEY_ID', // NOT SECRET
    amount: data.order.amount,
    order_id: data.order.id,
    name: 'ZenCommerce',
    prefill: {
      email: user.email,
      contact: user.phone,
      name: user.fullName,
    },
    theme: { color: '#53a20e' },
  };
  RazorpayCheckout.open(options)
    .then((paymentData) => {
      // Payment Success
      // Send paymentData.razorpay_payment_id to backend for verification and order completion
    })
    .catch((error) => {
      // Payment Failed
      alert(`Error: ${error.description}`);
    });
};
--
4. Backend: Verify Payment (Optional but recommended)
After payment, verify the signature on your backend using Razorpay’s SDK.

5. Update Order Status
On successful payment, update your order’s paymentStatus to "Paid" in your backend.

Summary
Create Razorpay order on backend.
Use Razorpay SDK in frontend to open payment modal.
On success, verify payment and update order.
